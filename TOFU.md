# Tofu gallery copy

This repository is Tofu's copy of **storytold/photocraft** (licence: Apache-2.0), listed in Tofu's app gallery as **PhotoCraft**.

- `main` mirrors the upstream repository and is never committed to by Tofu.
- `tofu` carries Tofu's own changes; tags named `pin/<date>` mark the versions the gallery points to.
- A visitor who chooses this app gets a private snapshot of the pinned version in their own Tofu account.
- Upstream is a Rust project; Tofu cannot build it, so this copy ships PhotoCraft's published web build (its own release artefact) rather than the Rust sources.

Upstream commit forked at: `ff4738810134d7f7e68b49f2e4f231b686282ff3`.
